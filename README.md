# HFE genetic testing service evaluation

This repository accompanies a retrospective service evaluation of an established HFE genetic testing service.

**Current status:** README only. No analysis code or data are included at this stage.

## Project overview

The project integrates historical HFE genetic-test records with routine laboratory biochemistry to examine:

- longitudinal service activity and patient-level diagnostic yield;
- ferritin and transferrin-saturation patterns at genetic testing;
- biochemical threshold concordance;
- repeat-request and comparable-result concordance;
- documented referral features associated with HFE genotypes.

## Analytical approach

Analyses are performed using deterministic, investigator-reviewed Python and R scripts. Patient-level analyses use pseudonymous identifiers and prespecified genotype, biochemical and statistical definitions.

## Data governance

Identifiable source data remain within the secure institutional environment and are not included in this repository. No names, medical-record numbers, dates of birth, free text, patient-level crosswalks or identifiable laboratory records will be uploaded. Any future repository materials will be limited to approved, non-identifying documentation, code and aggregate outputs.

## AI-assisted development

OpenAI Codex assisted with workflow design, code development, debugging, documentation and visualisation. Identifiable source data were not supplied to the AI system. Data processing and statistical analyses were executed locally using deterministic Python and R scripts and reviewed by the investigators.

## Availability

Analysis code may be added following governance review and completion of the service evaluation. Until then, this repository provides a stable project record for conference materials.
